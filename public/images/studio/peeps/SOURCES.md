# Hero crowd

- Component: https://skiper-ui.com/registry/skiper39.json (Skiper UI #39, by gxuri).
- Original inspiration: https://codepen.io/zadvorsky/pen/xxwbBQV
- Illustration: https://www.openpeeps.com/ (Open Peeps).
- Sprite source: https://skiper-ui.com/images/peeps/all-peeps.png
- Local asset: lossless WebP conversion of the original sprite sheet, 15 columns × 7 rows.

Skiper's registry permits personal and commercial modification and requires attribution for free use. Visible Skiper UI and Open Peeps links are included in the hero.
The adaptation uses a typed native canvas loop, fewer characters, reduced-motion handling, visibility suspension, and observer cleanup instead of GSAP.
